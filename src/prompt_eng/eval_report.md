# Eval Report — 结构化提取评测

## 项目背景

用 LLM 从杂乱文本中提取 `{"name", "phone", "address"}` 结构化 JSON。

- 模型：`deepseek-v4-flash`
- 调用：`llm_chat(messages, temperature=0)`（temperature=0 保证输出稳定）
- 代码：`src/prompt_eng/info_extractor.py` + `src/prompt_eng/eval_report.py`

## 测试方法

准备 10 条不同格式的测试数据，覆盖各种"脏"输入：

| 场景 | 样例 |
|------|------|
| 标准格式 | 张三，电话 13812345678，住在北京市海淀区... |
| 无标点 | 李四 13987654321 上海市浦东新区... |
| 口语化 | 你好我叫王五，手机13711112222，广州... |
| 电话带横杠 | 赵六电话136-3333-4444 深圳市... |
| 英文姓名 | I am John Smith, +86-135-1234-5678... |
| 括号分隔 | 吴十（电话：18866667777）浙江省杭州市... |

评测方式：模型输出与期望 JSON 完全相等记为正确，算准确率。
